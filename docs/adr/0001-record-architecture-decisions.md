# 1. Record architecture decisions

- Status: accepted
- Date: 2026-10-06

## Context
Cardholder handles sensitive data; reviewers and future contributors need to understand why the
security-relevant design looks the way it does.

## Decision
Significant decisions are recorded as short ADRs in `docs/adr`, numbered sequentially, using the
format *Context → Decision → Consequences*. Superseded ADRs are kept and marked as such.

## Consequences
Design changes that contradict an ADR require a new ADR.
