# 4. Minimum SDK 30

- Status: accepted
- Date: 2026-10-06

## Context
`BIOMETRIC_STRONG | DEVICE_CREDENTIAL` with `BiometricPrompt` and
`KeyGenParameterSpec.setUserAuthenticationParameters` (per-authenticator, time-bound keys) only work
consistently from Android 11 (API 30).

## Decision
`minSdk = 30`.

## Consequences
Covers the vast majority of active devices in 2026 and removes legacy code paths for authentication
and key generation.
