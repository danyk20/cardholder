# Shop logos

Cardholder does **not** bundle any logo files. For shops in the catalogue it stores the address of a
logo on [Wikimedia Commons](https://commons.wikimedia.org) whose licence allows reuse, and downloads it
only when the user chooses *Use official logo* for a card.

Logos are trademarks of their respective owners and are shown only to identify the shop a card belongs to.
Shops without a freely licensed logo (Boots, Carrefour, Kroger, Nectar) can use a logo uploaded by the user.
