Cardholder зберігає банківські картки, документи й картки лояльності в одному місці на вашому телефоні — у зашифрованому вигляді, без інтернету, реклами та стеження.

<b>Картки лояльності на касі</b>
• Штрихкод або QR-код кожної картки лояльності видно просто в списку
• Торкніться його, щоб показати код на весь екран із максимальною яскравістю для сканера
• Відскануйте код із пластикової картки камерою або введіть його вручну
• Підтримуються QR, EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, ITF, Codabar, PDF417, Aztec і Data Matrix

<b>Банківські картки</b>
• Номер картки, термін дії, ім’я власника та CVV
• Заповнення даних: просто прикладіть безконтактну картку до телефона (NFC)
• CVV завжди приховано, і він показується лише після підтвердження відбитком пальця, розпізнаванням обличчя або блокуванням екрана
• Автоматичне визначення платіжної системи

<b>Документи</b>
• ID-картки, паспорти, посвідчення водія та інші документи
• Країна видачі, номер документа й термін дії

<b>Фото обох боків</b>
• За бажання відскануйте лицьовий і зворотний бік будь-якої картки з автоматичним визначенням країв
• Фото зашифровано, і вони ніколи не залишають ваш пристрій

<b>Безпека та конфіденційність</b>
• Усі дані шифруються ключами, які зберігаються в захищеному сховищі вашого телефона
• Заблокуйте будь-яку картку, щоб її можна було відкрити лише відбитком пальця, розпізнаванням обличчя або блокуванням екрана
• Знімки екранів із конфіденційними даними заборонено
• Скопійовані номери видаляються з буфера обміну через хвилину
• Без акаунта, реклами й аналітики — ваші картки ніколи не залишають пристрій
• Додаток під’єднується до інтернету, лише коли ви вирішуєте завантажити офіційний логотип магазину чи банку

<b>Зручна організація</b>
• Пошук і фільтр за типом картки
• Сортування за назвою, датою додавання або у власному порядку
• Кольори й логотипи відомих магазинів і банків або власні зображення

<b>Зашифрована резервна копія</b>
• Експортуйте всі картки в один файл, захищений паролем, і відновіть їх на новому телефоні
