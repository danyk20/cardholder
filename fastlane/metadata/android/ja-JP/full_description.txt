Cardholder は、銀行カード、身分証明書、ポイントカードをスマートフォンにまとめて保管できるアプリです。すべて暗号化され、オフラインで動作し、広告やトラッキングはありません。

<b>レジでポイントカードを提示</b>
• リスト上で各ポイントカードのバーコードや QR コードをそのまま表示
• タップすると最大の明るさでコードを全画面表示し、すぐにスキャンできます
• プラスチックカードのコードをカメラでスキャン、または手動で入力
• QR, EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, ITF, Codabar, PDF417, Aztec、Data Matrix に対応

<b>銀行カード</b>
• カード番号、有効期限、カード名義人、CVV を保存
• 非接触型カードをスマートフォンにかざして情報を入力（NFC）
• CVV は常に非表示で、指紋認証、顔認証、または画面ロックの後にのみ表示
• 国際ブランドを自動で判別

<b>身分証明書</b>
• 身分証明書、パスポート、運転免許証など
• 発行国、証明書番号、有効期限

<b>カードの両面の写真</b>
• 必要に応じて、カードの表面と裏面を自動エッジ検出でスキャン
• 写真は暗号化され、デバイスの外に出ることはありません

<b>セキュリティとプライバシー</b>
• すべてのデータは、スマートフォンのセキュア ハードウェアに保管された鍵で暗号化
• カードをロックして、指紋認証、顔認証、または画面ロックでのみ開けるように設定可能
• 機密情報を含む画面ではスクリーンショットをブロック
• コピーした番号は 1 分後にクリップボードから削除
• アカウント不要、広告なし、分析なし。カードがデバイスの外に出ることはありません
• アプリがインターネットに接続するのは、お店や銀行の公式ロゴをダウンロードするときだけです

<b>自由に整理</b>
• カードの種類で検索と絞り込み
• 名前、追加日、または独自の順序で並べ替え
• 有名なお店や銀行の色とロゴを利用でき、独自のロゴのアップロードも可能

<b>暗号化バックアップ</b>
• すべてのカードをパスワードで保護された 1 つのファイルにエクスポートし、新しいスマートフォンで復元
