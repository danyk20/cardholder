Cardholder 将您的银行卡、证件和会员卡集中保存在手机上——全程加密、离线使用，没有广告，也没有跟踪。

<b>结账时出示会员卡</b>
• 每张会员卡的条形码或二维码都直接显示在列表中
• 点按即可以最高亮度全屏显示代码，方便扫描
• 用相机扫描实体卡上的代码，或手动输入
• 支持 QR, EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, ITF, Codabar, PDF417, Aztec 和 Data Matrix

<b>银行卡</b>
• 保存卡号、有效期、持卡人和 CVV
• 将非接触式卡片贴近手机即可自动填写信息（NFC）
• CVV 始终隐藏，只有通过指纹、人脸或屏幕锁定验证后才会显示
• 自动识别卡组织

<b>证件</b>
• 身份证、护照、驾驶证等
• 签发国家/地区、证件号码和有效期

<b>卡片正反面照片</b>
• 可选择扫描任意卡片的正面和背面，并自动检测边缘
• 照片经过加密，绝不会离开您的设备

<b>安全与隐私</b>
• 所有内容均使用存储在手机安全硬件中的密钥加密
• 可锁定任意卡片，只有通过指纹、人脸或屏幕锁定才能打开
• 在显示敏感信息的界面上禁止截屏
• 复制的号码会在一分钟后从剪贴板中清除
• 无需账号，没有广告，没有数据分析——您的卡片绝不会离开您的设备
• 只有在您选择下载商店或银行的官方徽标时，应用才会联网

<b>按您的方式整理</b>
• 按卡片类型搜索和筛选
• 按名称、添加日期或自定义顺序排序
• 为知名商店和银行提供颜色和徽标，也可以上传您自己的徽标

<b>加密备份</b>
• 将所有卡片导出为一个受密码保护的文件，并在新手机上恢复
