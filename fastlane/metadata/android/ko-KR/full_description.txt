Cardholder는 은행 카드, 신분증, 멤버십 카드를 휴대전화 한곳에 보관합니다. 모든 정보는 암호화되고 오프라인으로 작동하며, 광고와 추적이 없습니다.

<b>계산대에서 바로 멤버십 카드 제시</b>
• 목록에서 각 멤버십 카드의 바코드 또는 QR 코드를 바로 확인
• 탭하면 최대 밝기의 전체 화면으로 코드가 표시되어 바로 스캔 가능
• 실물 카드의 코드를 카메라로 스캔하거나 직접 입력
• QR, EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, ITF, Codabar, PDF417, Aztec, Data Matrix 지원

<b>은행 카드</b>
• 카드 번호, 유효기간, 카드 소유자, CVV 저장
• 비접촉식 카드를 휴대전화에 대면 정보가 자동으로 입력됨(NFC)
• CVV는 항상 숨겨지며 지문, 얼굴 또는 화면 잠금 인증 후에만 표시
• 카드 브랜드 자동 인식

<b>신분증</b>
• 주민등록증, 여권, 운전면허증 등
• 발급 국가, 신분증 번호, 만료일

<b>카드 양면 사진</b>
• 원하는 경우 자동 가장자리 감지로 카드 앞면과 뒷면 스캔
• 사진은 암호화되며 기기 밖으로 나가지 않음

<b>보안 및 개인정보 보호</b>
• 모든 정보는 휴대전화의 보안 하드웨어에 보관된 키로 암호화
• 카드를 잠가서 지문, 얼굴 또는 화면 잠금으로만 열 수 있도록 설정
• 민감한 정보가 있는 화면에서는 스크린샷 차단
• 복사한 번호는 1분 후 클립보드에서 삭제
• 계정, 광고, 분석 없음 - 카드 정보가 기기 밖으로 나가지 않음
• 매장 또는 은행의 공식 로고를 다운로드하도록 선택한 경우에만 인터넷에 연결

<b>원하는 방식으로 정리</b>
• 카드 유형별 검색 및 필터
• 이름, 추가한 날짜 또는 사용자 지정 순서로 정렬
• 잘 알려진 매장과 은행의 색상 및 로고 제공, 직접 업로드도 가능

<b>암호화된 백업</b>
• 모든 카드를 비밀번호로 보호된 하나의 파일로 내보내고 새 휴대전화에서 복원
