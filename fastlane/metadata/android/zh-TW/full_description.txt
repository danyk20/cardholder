Cardholder 將你的銀行卡、證件和會員卡集中存放在手機上——全程加密、可離線使用，沒有廣告，也沒有追蹤。

<b>結帳時出示會員卡</b>
• 每張會員卡的條碼或 QR 碼都直接顯示在清單中
• 輕觸即可以最高亮度全螢幕顯示代碼，方便掃描
• 使用相機掃描實體卡片上的代碼，或手動輸入
• 支援 QR, EAN-13, EAN-8, UPC, Code 128, Code 39, Code 93, ITF, Codabar, PDF417, Aztec 和 Data Matrix

<b>銀行卡</b>
• 儲存卡號、有效期限、持卡人和 CVV
• 將感應式卡片靠近手機即可自動填入資料（NFC）
• CVV 一律隱藏，只有通過指紋、臉孔或螢幕鎖定驗證後才會顯示
• 自動辨識發卡組織

<b>證件</b>
• 身分證、護照、駕照等
• 核發國家/地區、證件號碼和有效期限

<b>卡片正反面相片</b>
• 可選擇掃描任何卡片的正面和背面，並自動偵測邊緣
• 相片經過加密，絕不會離開你的裝置

<b>安全與隱私</b>
• 所有資料都使用存放在手機安全硬體中的金鑰加密
• 可鎖定任何卡片，只有通過指紋、臉孔或螢幕鎖定才能開啟
• 在顯示敏感資料的畫面上禁止螢幕截圖
• 複製的號碼會在一分鐘後從剪貼簿中清除
• 不需要帳戶，沒有廣告，沒有數據分析——你的卡片絕不會離開你的裝置
• 只有在你選擇下載商店或銀行的官方標誌時，應用程式才會連上網路

<b>依你的方式整理</b>
• 依卡片類型搜尋和篩選
• 依名稱、新增日期或自訂順序排序
• 為知名商店和銀行提供顏色和標誌，也可以上傳你自己的標誌

<b>加密備份</b>
• 將所有卡片匯出成一個受密碼保護的檔案，並在新手機上還原
